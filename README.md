# Demotivator

An Unmotivational Generator: click the button and get a dramatic animation, a sad trombone, and a fresh piece of anti-motivation every time.

Made by **Abdi (Abdullah Mohsin)** as a **Boba Bash** project for the **Hack Club** Boba Bash event.

Built with plain HTML, CSS and JavaScript in a single `index.html`. All sounds are synthesized in the browser with the Web Audio API, so there are no audio files.
